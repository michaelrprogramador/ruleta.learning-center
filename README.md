# 🎡 Ruleta Learning Center

Aplicación web para clases de Desarrollo Emocional.

## Funciones
- Giro animado con selección aleatoria.
- Agregar, editar o eliminar actividades.
- Elegir colores de las actividades.
- Crear, duplicar y eliminar varias ruletas.
- Guardado automático en el navegador.
- Exportación e importación de todas las ruletas mediante JSON.
- Diseño adaptable a computador, tablet y móvil.

## Publicar con GitHub Pages
En el repositorio, abre **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**; elige `main` y `/(root)`, y pulsa **Save**.

Dirección prevista: https://michaelrprogramador.github.io/ruleta.learning-center/

**Importante:** GitHub Pages aloja la aplicación, pero no sincroniza las actividades entre distintos dispositivos. Cada navegador conserva sus ruletas localmente. Usa los botones Exportar/Importar para compartirlas. No incluyas información personal de estudiantes.
